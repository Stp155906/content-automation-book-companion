# Content Automation Book Companion

Welcome. This repository holds the safe, copy-and-paste templates that go with the book.

Start with the folder that matches the chapter you are reading. Copy the template, replace every `PASTE_YOUR_...` placeholder with your own value, and then return to the book for the explanation of each step.

## Start here

1. Read **Part 1** of the book to choose your content format.
2. Open [`templates/drive-folder-structure.md`](templates/drive-folder-structure.md) and set up your Google Drive folders.
3. Copy [`templates/post-copy-template.csv`](templates/post-copy-template.csv) into a new Google Sheet.
4. Copy the complete working-style demo: [`templates/tiktok-carousel-draft-demo.gs`](templates/tiktok-carousel-draft-demo.gs), then follow [`guides/tiktok-carousel-demo-setup.md`](guides/tiktok-carousel-demo-setup.md) line by line.
5. Return to the book before connecting any third-party account.

## What belongs here

- Generic prompts that readers can copy and customize.
- Safe example CSV files and folder structures.
- Starter scripts with clear placeholders.
- A complete generic TikTok carousel draft demo with safety checks and clear replace-this sections.
- Troubleshooting notes that can be updated after the book is published.

## What never belongs here

Do not upload your own TikTok client secret, OAuth token, refresh token, Vercel secret, real Google Drive folder ID, email address, or private screenshots. Anyone can copy a public GitHub repository.

## How to use placeholders

Whenever you see a value like `PASTE_YOUR_DRIVE_FOLDER_ID`, replace only the placeholder. Do not paste your private values back into this public repository.

## Reader note

This companion supports a **draft-first** TikTok workflow. It prepares a draft for the account owner to review, edit, add music to, and publish manually in TikTok.
