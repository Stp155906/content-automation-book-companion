# Content Automation Book Companion

Welcome. This repository holds the safe, copy-and-paste templates that go with the book.

Start with the folder that matches the chapter you are reading. Copy the template, replace every `REPLACE_THIS...` placeholder with your own value, and then return to the book for the explanation of each step.

## Start here

1. Read **Part 1** of the book to choose your content format.
2. Start at [`start-here/README.md`](start-here/README.md) and follow the steps in order.
3. Copy the complete script in [`templates/tiktok-carousel-draft-demo.gs`](templates/tiktok-carousel-draft-demo.gs).
4. Use [`examples/carousel-example/README.md`](examples/carousel-example/README.md) to compare your finished folder with a complete example.
5. If something fails, open [`troubleshooting/README.md`](troubleshooting/README.md) before changing code.

## What belongs here

- Generic prompts that readers can copy and customize.
- Safe example CSV files and folder structures.
- A complete generic TikTok carousel draft script with safety checks and clear replace-this sections.
- A generic private Vercel media relay that works with the script.
- Every configuration value, permission, file name, and test step in one numbered order.
- An example system readers can compare against and an updates folder for post-publication changes.
- Troubleshooting notes that can be updated after the book is published.

## What never belongs here

Do not upload your own TikTok client secret, OAuth token, refresh token, Vercel secret, real Google Drive folder ID, email address, or private screenshots. Anyone can copy a public GitHub repository.

## How to use placeholders

Whenever you see a value like `REPLACE_THIS_WITH_YOUR_DRIVE_FOLDER_ID`, replace only the placeholder. Do not paste your private values back into this public repository.

## Reader note

This companion supports a **draft-first** TikTok workflow. It prepares a draft for the account owner to review, edit, add music to, and publish manually in TikTok.
