# Start Here

Do these seven steps in order. Do not skip ahead to the schedule until the manual test works.

1. [Before you start](01-before-you-start.md) - Understand what this workflow does and what stays private.
2. [Google Drive and CSV](02-google-drive-and-csv.md) - Create the exact content folder and metadata file.
3. [TikTok Developer App](03-tiktok-developer-app.md) - Turn on the right API features and create credentials.
4. [Private Vercel Relay](04-private-vercel-relay.md) - Give TikTok short-lived image links without opening your Drive folder.
5. [Apps Script Copy Paste](05-apps-script-copy-paste.md) - Paste the full code and add your own values.
6. [Connect Test Schedule](06-connect-test-schedule.md) - Preview, connect, test once, then schedule.
7. [Complete demo walkthrough](07-full-demo-walkthrough.md) - Read the whole flow once before you repeat it on your own account.
8. [Detailed script reference](08-detailed-script-reference.md) - Keep this open while you paste the code and add your private values.

## One rule that prevents most mistakes

If you cannot prove you have the correct images and `post-copy.csv` in today's exact dated folder, do not send anything. Fix the folder first.
