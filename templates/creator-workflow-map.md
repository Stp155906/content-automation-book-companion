# Creator Workflow Map

Copy this page into a Google Doc, Notion page, or notebook before setting up a
new automation. One map equals one content workflow. Do not combine unrelated
niches in one folder or one script.

```text
WORKFLOW NAME:

PLATFORM:
TikTok Upload to TikTok (draft-first)

NICHE / ACCOUNT:

CONTENT FORMAT:
Single image / carousel / short video

GOOGLE DRIVE PARENT FOLDER:
(paste the folder name here; keep the ID private)

DAILY FOLDER FORMAT:
YYYY-MM-DD

REQUIRED FILES:
Example: 01.png through 07.png, plus post-copy.csv

CSV HEADERS:
Title, SEO Description, CTA

TIMEZONE:

SCHEDULE:
Example: once daily, 9:00 AM

ALERT EMAIL:

WHAT SHOULD HAPPEN IF CONTENT IS MISSING?
Stop and email me. Never use an older folder.

WHAT COUNTS AS A DUPLICATE?
The same exact images and CSV file content for the same dated folder.

FINAL HUMAN STEP:
Open the TikTok inbox notification, edit if wanted, and tap Post in TikTok.
```

## Why this page matters

Automation becomes reliable when it has one predictable source folder, one
file pattern, one schedule, and one clear definition of success. Complete this
map before asking an AI assistant to write or customize code.
